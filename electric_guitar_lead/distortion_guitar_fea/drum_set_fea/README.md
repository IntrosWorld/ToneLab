# Drum Set FEA

This folder renders track 3 (`Drums`) from `../ref/tab2.gp`. Kick and snare use
clamped circular membrane modes; hi-hat and crash use circular plate modes.
GP articulation IDs select the physical instrument for every original hit.
No drum samples or prerecorded impulse responses are used.

Run: `python render_tab2_drums.py`
